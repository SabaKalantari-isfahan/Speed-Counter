🎮 Speed Counter

A fun and interactive counter built with HTML, CSS, and JavaScript.

The project has a colorful cartoon-style interface with animated buttons and a dynamic counter.

✨ Features

* ▶️ Start the counter
* ⏹️ Stop the counter
* 🔢 Real-time counter
* 🎨 Cartoon-style UI
* ✨ Button hover and click animations
* 🚀 Counter animation
* 📱 Responsive design
* 🛑 Prevents multiple timers from running at the same time

🛠️ Technologies

* HTML5
* CSS3
* JavaScript

🚀 How to Run

1. Clone the repository:

git clone https://github.com/SabaKalantari-isfahan/Speed-Counter.git

2. Open the project folder.
3. Open index.html in your browser.

That’s it! 🎉

🎮 How to Use

Start

Click the START button to begin counting.

Stop

Click the STOP button to stop the counter.
